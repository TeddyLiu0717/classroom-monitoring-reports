# Monitoring reports

A public reading site for explicitly approved monitoring reports and focused video evidence.

Open index.html on GitHub Pages. Reports use anonymous handles and aggregate observations. Participant windows and unnecessary audio are removed from shared clips. This repository is not a raw-data or credential archive. Source evidence stays outside this repository.

No configuration or credentials are required for readers. Copyright in reports and course/video assets remains with their respective holders; public reading does not grant a redistribution licence.
